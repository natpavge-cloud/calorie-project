# Проект модуля. Нейросеть для предсказания калорийности блюд

Мультимодальная нейросеть для предсказания калорийности блюд по фотографии и текстовому описанию ингредиентов.

## Задача

На вход подаётся фотография блюда (`rgb.png`) и список ингредиентов на английском языке. На выходе — калорийность блюда в ккал.

Ключевая идея: модель предсказывает не абсолютную калорийность, а плотность (ккал на 100 г), после чего калорийность восстанавливается как `calories = density * mass / 100`. Это защищает модель от тривиального выучивания зависимости «калории ≈ масса» и заставляет учитывать визуальную и текстовую модальности.


## Архитектура

Модель состоит из трёх веток, объединяемых на этапе позднего слияния (late fusion):

- **Image Encoder:** `EfficientNet-B0` (timm, pretrained) -> проекция в вектор размерности 256.
- **Text Encoder:** `DistilBERT` (`distilbert-base-uncased`) -> проекция в вектор размерности 256 (среднее по токенам с учётом attention mask).
- **Mass:** нормализованное значение массы порции (1 признак).

Далее векторы конкатенируются в общий вектор (512 + 1), проходят через полносвязный слой (MLP) и финальный линейный слой (`Linear(256, 1)`) без функции активации.

- **Loss:** `L1Loss` (напрямую оптимизирует MAE).
- **Оптимизатор:** AdamW с раздельными learning rate для энкодеров и классификатора.
- **Mixed precision (AMP)** для ускорения обучения.


## Обучение

- **Эпохи:** 20
- **Batch size:** 4
- **GPU:** Tesla T4
- **Optimizer:** AdamW
  - `text_encoder`: 1e-5
  - `image_encoder`: 1e-4
  - `classifier` и проекционные слои: 1e-3
- **Scheduler:** ReduceLROnPlateau (фактор 0.5, patience=2)
- **Аугментации:** RandomResizedCrop, HorizontalFlip, ColorJitter
- **Воспроизводимость:** Seed = 42
- **Время обучения:** ~36 минут

## Анализ ошибок

Для пяти объектов с максимальной абсолютной ошибкой в ноутбуке приведены фотографии, списки ингредиентов, истинные и предсказанные значения калорийности. Основные причины крупных ошибок:

- Высокая доля скрытых калорий (орехи, сыры, масла), которые плохо различимы на фото (модель видит лёгкий салат с зеленью, но не оценивает калорийность миндаля).
- Нестандартные сочетания ингредиентов, редко встречавшиеся в train (например, пицца с курицей и ананасом).
- Систематическое занижение плотности калорийных блюд, где визуальный объем не соответствует их питательной ценности.
